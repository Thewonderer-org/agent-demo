Guide for workflows 

This talk is a quick guide for workflows.
Every time a workflow is being looked up in our organisation, the first thing to understand is what team the user belongs to. If that is not available, then just ask the user.
Based on that:
- If the user is searching for service scaffolding workflows, suggest that from the list of workflows.
- If the user is looking for a workflow that does not exist in the list, then suggest creating one.
